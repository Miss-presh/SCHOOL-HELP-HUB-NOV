# Schoolhelphub

A premium online tutoring platform connecting families with qualified tutors across Nigeria, the United Kingdom, and beyond.

## 🌍 Overview

Schoolhelphub helps children aged **5–16** succeed through live online lessons delivered by experienced tutors following a structured teaching standard.

Our programmes cover:

- Mathematics
- English Language
- Science
- Coding & Technology
- 11+ Preparation
- GCSE
- WAEC
- NECO
- BECE
- SAT & ACT

Every lesson includes a written progress report so parents always know how their child is improving.

---

## ✨ Features

- 🎓 Qualified Nigerian & UK tutors
- 👨‍🏫 Small group and one-to-one lessons
- 📚 Curriculum-aligned teaching
- 📋 Written report after every lesson
- 📈 Progress tracking
- 🌍 Designed for families in Nigeria, UK, USA, Canada & UAE
- 📱 Responsive premium landing pages
- 💬 WhatsApp integration
- 📝 Google Sheets booking & contact forms

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/Miss-presh/Schoolhelphub-latest.git
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```
